# Bd Weather Widget

This application displays current weather conditions and icons for major cities in Bangladesh.

## Overview

The application listens for selection changes on a dropdown menu containing predefined city objects. When a user picks a city, the interface updates the temperature, condition text, and icon indicators dynamically.

## Highlights

- Select from multiple Bangladeshi cities
- Dynamic weather icon updates
- Detailed humidity and wind metrics
- Clean flat design layout

## Getting started

Open `index.html` in a browser. No install or build step.

## Layout

- `index.html`: Main markup structure for the weather app
- `style.css`: Styles using design system variables
- `script.js`: Handles city data and updates interface elements
